# 字幕与章节

## 字幕：AI 校对流程（5b）
输入 `captions_draft.json`（已按成片时间轴、已去除被剪掉的口水词），逐条检查并另存 `captions.json`（结构不变：`[{id,start,end,text}]`）：
1. **同音错字/ASR 误识**：结合主题纠正（"克劳德"→"Claude"，"瑞威"→"Railway"，"泡森"→"Python"）。专有名词用官方大小写，中英文之间不加空格也可，**全片统一**。
2. **术语表**：用 01 步 `--prompt` 提供的术语一致；若 transcript.txt 里同一词出现多种写法，统一。
3. **断句**：每条 ≤ 16 个汉字（英文 ≤ 44 字符）、一行；在语义停顿处断，不拆词；过长就拆成两条并**按字数比例切分 start/end**。
4. **去口语赘词**：字幕可比口播更精炼（删"就是说""然后呢"），但不能改变原意；保持与声音节奏同步。
5. **标点**：句尾不加标点（逗号/句号），保留问号/感叹号。
6. **高亮**：每条最多 1 处 `**关键词**`（命令、按钮名、数字、结论），渲染为黄色。
7. **与浮层冲突**：字幕在底部 18%，不与提示框同区。
8. 时间轴：start 不早于声音；相邻条不重叠；最短 0.9s。
9. 另导出 `captions.srt`（09 步自动）供平台上传，**平台字幕建议用 srt 而非烧录**，成片已烧录一份用于短视频平台。
> 校对后抽查：随机听/看 5 处，确认字幕与口播一致。

## 章节
- 4–7 章，每章 25s–150s；标题 2–6 字，名词/动词短语（"痛点""安装""配置""实测""总结"），避免"第一步"。
- 第一章在 Hook 之后开始；进度条在 Hook 结束时滑入，片尾 CTA 前淡出。
- 章节边界应与**话题切换**一致，且落在剪辑点上；章节过短（<8% 宽度）进度条只显示序号。
- 09 步生成 `chapters.txt`（YouTube 格式 `00:00 开场`，首条必须 00:00，至少 3 条，每条 ≥10s），写进简介即可生成平台章节。
