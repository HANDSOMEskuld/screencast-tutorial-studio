# 视觉系统：Apple 液态玻璃 (Liquid Glass) 风格

实现位于 `templates/overlay.html`（CSS 变量 + 组件）。设计坐标系固定 **1920×(1080)**，自动缩放到任意分辨率。

## 1. 玻璃材质
- **真实毛玻璃（`--glass real`，默认）**：叠层里的玻璃面板只提供形状；同一时间轴再渲染一份「遮罩」，ffmpeg 把**底层录屏的模糊+提亮饱和版本**按遮罩合成到面板下 → 真正的背景模糊（backdrop-filter 在透明叠层里无法做到，所以这样做）。
- **快速预览（`--glass fake`）**：面板用较不透明的深色填充，不做模糊，渲染快一倍。
- 面板：圆角 28–44px、1.5px 半透明描边、顶部 1.5px 内高光、左上到右下的镜面渐变高光、大范围柔和投影。
- 深色(`dark`)：填充 `rgba(32,34,44,.42)`，文字白；浅色(`light`)：填充 `rgba(255,255,255,.46)`，文字深色。按录屏背景明暗选：深色 IDE/终端 → 浅色玻璃更醒目；浅色网页 → 深色玻璃。

## 2. 色彩令牌（Apple 系统色）
| 用途 | 色值 |
|---|---|
| 主色/进行中 | `#0A84FF`（可用 `meta.accent` 换品牌色） |
| 完成/成功 | `#30D158` |
| 警告/踩坑 | `#FF453A` |
| 提示/小技巧 | `#FF9F0A` |
| 高亮关键词 | `#FFD60A` |
| 次要点缀 | `#BF5AF2` |
文字：主 `#fff`，次 78% 白，弱 46% 白。字体栈：`-apple-system, SF Pro Display, PingFang SC, Noto Sans CJK SC`。

## 3. 动效语言
- **入场**：`back.out(1.5)` 轻微过冲弹入（0.5–0.6s），带 8–16px 位移与 0.9→1 缩放；图标用 `elastic.out` 弹跳。
- **出场**：0.3–0.4s 淡出+轻微上移+缩小，**比入场快**。
- **连接线/圈选**：描边绘制 (strokeDashoffset) 0.55s `power2.inOut`；圈选框 `back.out(2)` 落下后做 2–3 次 1.035 倍呼吸。
- **定时条**：提示框底部细线匀速收缩 = 剩余显示时间，观众知道何时消失。
- **节奏**：同屏动效不超过 2 个；动效时长 ≤ 0.7s；任何元素停留 ≥ 1.8s 以便阅读（文字量大则 ≥ 2.5s）。
- 确定性：所有动画挂在**一条 paused GSAP 时间轴**上，无随机/时钟，保证逐帧可复现（HyperFrames 要求）。

## 4. 组件与安全区
| 组件 | 位置 | 用途 | 参数 |
|---|---|---|---|
| **章节进度条** | 顶部 y=20, 左右 90px, 高 58 | 全片章节地图 | 自动。宽度∝章节时长；三态：已完成=绿勾+绿描边、进行中=主色描边发光+**章内进度填充**、未开始=暗；窄章节只显示序号 |
| **字幕** | 底部 64px 居中 | 口播文字 | `captions.json`，`**词**` 黄色高亮 |
| **callout 提示框** | 右侧 x=1380 y=200（可 `pos`） | 说明/提醒 | icon+标题(≤12字)+正文(≤30字)+定时条 |
| **ring 圈选** | 归一化坐标 | 指出点击处 | 主色描边+光晕；`spot:true` 聚光灯暗化其余 |
| **step 角标** | 左上 (90,100) | "STEP n" | 数字+短语 |
| **bignote 大字报** | 屏幕上 1/3 居中 | 重点/警告/情绪点 | tone: info/warn/success/tip，warn 带抖动 |
| **B-roll 卡片** | pip: 右上 620×380；full: 居中 1240×680 | 原理/对比/数据/情绪 | 见 03-broll-library |
| **快进徽章** | 右下 | 加速段提示 "⏩ 4× 快进" | 自动 |
| **CTA** | 屏幕上 30% 居中 | 点赞/关注/评论 | 图标依次弹跳 |
| **Hook 标题** | 屏幕上 16% | 开场钩子 | 逐字入场+下划线扫过 |

安全区（不可放浮层）：底部 18%（字幕）、**正在操作的区域**（看联系表判断；用 ring 圈而不是盖）。左右两侧默认各留 70px 边距。
