# 验收清单（9b）

先读 `qa_report.md`，再用图片查看 `qa/*.jpg`（每个关键帧 960px）。

## 画面
- [ ] Hook 帧：标题清晰、不超出安全区、预告画面足够有冲击
- [ ] 每个 callout/ring：没遮住光标/按钮，圈选位置准确
- [ ] 毛玻璃面板边缘无"模糊色块突然出现"（若有：提高 overlay 渲染 fps 或改 `--glass fake`）
- [ ] 章节进度条：当前章高亮、已过章为绿勾、未到章暗；标签无截断
- [ ] 字幕：无错别字、不压住提示框、文字对比度足够（浅色画面上仍清晰）
- [ ] B-roll：文字 ≥26px、无溢出、动画完整"入-停-出"
- [ ] 结尾 CTA：不压住最后一句话（需要时加 `cta.extend`）

## 声音
- [ ] 无爆音/咔哒（切口），无突然的房间底噪变化
- [ ] 人声在 BGM 上清晰；BGM 在人声间隙回升自然
- [ ] 音效不过密、不盖人声；响度 -14~-16 LUFS，TP ≤ -1.0

## 叙事与节奏
- [ ] 前 3 秒有钩子；20 秒内说清"看完能得到什么"
- [ ] 章节顺序合理，没有"用到还没讲的东西"
- [ ] 无重复/矛盾/失败片段残留；无隐私信息
- [ ] qa_report 没有 >8s 静态空窗；B-roll ≥1/分钟
- [ ] 情绪曲线符合 plan：低谷处有共鸣、高点处有奖励、结尾最满足
- [ ] 总时长合理（教程 5–10 分钟最佳；>12 分钟需更强章节与节奏）

## 常见修复对照
| 问题 | 回到 | 做法 |
|---|---|---|
| 某处剪掉了需要的内容 | 2 | 调整 segment src，重跑 3→9 |
| 提示框遮挡 | 2/6 | 改 `pos`/`at` 或 ring；重跑 5→9 |
| 字幕错字 | 5b | 改 captions.json；重跑 6→9 |
| BGM 太响/太弱 | 8 | `--bgm-db -26`；重跑 8→9 |
| 太拖 | 3 | `--preset tight` |
| 渲染太慢 | 7 | `--glass fake --quality draft --fps 24` 预览 |
