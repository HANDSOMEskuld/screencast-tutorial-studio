# 设计目标与验收标准

> 本技能要满足的目标。修改技能前对照本文，不得偏离。

## 目标
做一个 AI Agent 可调用的**视频剪辑技能**，把"录屏 + 高清音频"变成专业、有吸引力的成片。用户以后直接调用即可。
素材类型：**录屏演示**——演示某个软件怎么用，或某个教程怎么做、怎么执行。

## 流程要求
### 第 1 步：合并与 AI 分析
- 合并视频文件与高清音频文件。
- 合并后由 **AI 分析内容**，找到完美的视频流程和逻辑（要真正发挥 AI 的判断力），再按这个整体流程剪辑。

### 第 2 步：剪辑与加工
- (a) **粗剪去噪**：去除口水词、语气词、停顿等不必要内容，让视频流畅，不打断观看体验。
- (b) **B-roll**：在合适位置添加 B-roll，用动画演示原理、情绪。**由 AI 判断加在哪里并合成动画**。动画要清晰、可爱、吸引人、美观专业。
- (c) **提示框与动效**：在录屏的重要演示、说明、提示处添加带动效的提示框，动效美观、简洁、清晰。
- (d) **BGM 和音效**。

### 第 3 步：剪辑完成后
- **字幕**：AI 识别、改错、分析，达到符合主题的纠错效果和最佳视觉体验。
- **章节划分**，并在视频**顶部加进度条**：清楚显示分几章、各在什么时间点，并能分辨**已播放 / 正在播放 / 未播放**的章节。

## 特别注意
### 1. 整体逻辑
- **宏观**：录制时顺序/说明逻辑可能不完美，可能需要调整前后顺序或改变说明方式。必须结合内容分析出最合适的逻辑——这决定整体效果与脉络，**非常重要**。
- **微观**：处理前后矛盾、重复、失败的内容。

### 2. B-roll 与提示说明画面
- 要专业：不仅清楚演示/说明/提醒重点，还要画面精美、清晰、有吸引力，动效精良。
- **参考效果**：近期"用 Claude + HTML 做视频"很火（用户原话写 Claude 3.5，实指当前最新 Claude 模型的效果），要达到同等水平。
- **风格**：偏 **Apple 风格**——最新苹果系统及其动效，**半透明毛玻璃**，需具体分析与选择。

### 3. 节奏与吸引力（完播率、点击率）
1. **开篇 Hook**：前 3–5 秒抛出钩子。
2. **宏观情绪曲线**：符合文艺作品的情绪曲线（先低后高 / 先高后低皆可），参照《丑小鸭》《狮子王》类作品的宏观情感曲线。
3. **微观节奏**：一句话不能长时间停顿；用动效、音效吸引人；遇到 5–10 秒无聊的演示/观看，要用情绪点**快节奏切入**持续抓注意力。
4. **结尾引导**：提醒点赞、关注、留言等互动。
- 其他有助于留存的方法也应考虑。

## 最终验收标准
1. 制作专业，动效精良，音效精美、吸引人。
2. 整体脉络清晰合理，节奏优美。
3. 能吸引观众。
4. 以 Agent 技能形式交付，可重复调用。
